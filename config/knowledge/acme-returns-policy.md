# Returns

## Standard returns window

You can return most items within 7 days of delivery. The item should be in a
condition that allows resale, with its original packaging where possible.

## How a return is different from a replacement

A return sends the item back and refunds you. A replacement sends you the same item
again and does not involve a refund. A damaged item is normally handled as a
replacement, because the fastest fix is usually a working item rather than money
back.

## Items excluded from returns

Gift cards, perishable goods and digital products are not returnable. This is the
same list that applies to replacements.

## Orders that have not arrived

An order that has not been delivered cannot be returned. If an order is late,
that is a delivery question rather than a returns question, and a colleague will
help you track it.
